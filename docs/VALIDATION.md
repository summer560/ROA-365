# 구현 확인 기록

2026-09-13에 다음을 확인했습니다.

- `npm run build`: 홈페이지, 7개 카테고리, 404 등 HTML 9개와 sitemap·robots 생성 성공.
- `npm run verify`: 내부 링크·이미지·스크립트 등 238개 참조, 본문 171개 문장의 선택 원고 일치, 중복 ID 및 초안 미노출 확인.
- 임시 캐릭터·기록 Markdown을 사용해 목록, 상세 페이지, 카테고리 연결, 파일명과 다른 slug, 사이트맵 생성 확인. 검증 파일을 제거하고 최종 빌드를 다시 실행했습니다.
- 반응형 CSS와 감소된 모션 설정, 접근 가능한 Grade 탭과 자바스크립트 없이 본문을 읽을 수 있는 구조를 구현했습니다.

실제 브라우저 화면 검증은 미완료입니다. 내부 점검 서버가 정해진 주소에서 정상 시작하지 않아 브라우저 화면과 모바일 렌더링을 확인하지 못했습니다. Astro의 로컬 서버 host·port는 설정 파일에도 명시했습니다. 다음에 화면 확인이 가능할 때 1440px, 768px, 390px, 320px 너비에서 그림 위치, 메뉴, 긴 제목, 조직 포스터, Grade 선택과 목차 스크롤을 확인해야 합니다.

Cloudflare 계정에는 연결하거나 배포하지 않았습니다. README의 설정으로 배포한 후 실제 주소에서 최종 화면을 확인해야 합니다.
