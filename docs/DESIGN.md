# ROA 사이트 구성

## 기준과 공개 범위

기준 원고는 Google 문서 「roa 웹사이트 구성요소」입니다. 「ROA 설정집 정리」나 과거 대화의 설정은 사용하지 않습니다. 확인한 원고 사본은 `docs/source/website-components.txt`이며 이 폴더는 빌드 결과에 포함되지 않습니다.

- 원고 확인 시점: 2026-09-13. Google 문서 수정 시점: 2026-09-13 05:39:41 UTC.
- 연도 2026과 ‘한국 ROA 지부 특수편성국 신설’은 최초 제작 요청에 사용자가 직접 명시한 정보입니다. 원고의 연표에 해당 연도가 없으므로 이 예외를 `timeline.json`에 명시했습니다. 설명문은 구성요소 문서의 한국지부 문단입니다.
- 원고의 말투 ‘했죠’를 ‘했습니다’로, 외계 세력 문단 첫머리의 여는 따옴표를 정리했습니다. 그 외 본문은 문단 묶음과 순서만 편집했습니다.
- 숫자, 코드, 장식 문구는 페이지 편집 요소입니다. 사건 번호, 기관 규정, 설정상의 고유 기호를 새로 만들지 않습니다.
- 상위 존재는 ALIEN, 집행관·국제 지부는 ORGANIZATIONS, 현대 사회·민간 레인저 산업은 ABILITY에 배치했습니다.
- 원고에 있는 공식 앱과 비상 호출기는 ARCHIVE가 준비 중이므로 현재 출력하지 않습니다. 원고 사본에 유지합니다.
- 캐릭터는 공개 프로필을 받기 전까지 Coming Soon입니다. 임시 메인 일러스트를 캐릭터 신원이나 설정과 연결하지 않습니다.

## 디자인 시스템

시각적 방향은 ‘국제 재난대응기관이 발행하는 스트리트 매거진’입니다. 메인 비주얼과 큰 ROA 타이포그래피, 잘린 모서리, 기울어진 포스터, 경고 테이프, 숫자 중심의 카드가 공통 요소입니다. Zenless Zone Zero는 큰 화면 구성과 대비의 참고이며 로고나 게임 에셋을 사용하지 않습니다.

| 화면 | 구성 |
| --- | --- |
| HOME | 월별 교체 일러스트 → WORLD·ABILITY·ALIEN·RANGER 카드 → 핵심 연표 → 세 조직 포스터 → 준비 중 메뉴 |
| WORLD | 큰 표제 → 세계관 → 이상현상·함정 → 공개용 축약 연표 |
| ABILITY | 약 2% 인구 그래픽 → 정의·발현 → 사회·등록제 → 현대 직업·민간 산업 |
| ALIEN | THEY ARE NOT ONE SPECIES. → 종족 → 외인혼혈 → 범죄 → 상위 존재 |
| RANGER | 역할·의무복무 → 복무 유형 → 키보드 조작 등급 카드 → 사건 위험도 → 편성·국제 파견 |
| ORGANIZATIONS | 세 조직 포스터 → 조직별 설명 → 집행관 → 미국·한국 지부 |
| ARCHIVE / CHARACTERS | Coming Soon. 캐릭터 Markdown 추가 시 목록과 상세 페이지 자동 생성 |

주 색상은 #111111 / #FFD400 / #F5F5F0입니다. 관리국은 흰 공문서와 붉은 강조, ORIGIN은 검정 전단지와 붉은 제목, ALIEN은 애시드 그린·보라, 이상현상은 시안·보라를 사용합니다. 기관들의 주장을 원고대로 나란히 보여줍니다.

본문은 16px 이상, 좁은 읽기 폭, 한국어 단어 단위 줄바꿈을 사용합니다. 보조 메타데이터만 작게 표시합니다. 모바일에서는 홈 카드를 2열, 조직 포스터와 설명문을 1열로 재구성합니다. 목차는 내부 가로 스크롤을 허용하고 페이지 전체 가로 넘침은 방지합니다.

## 재사용 컴포넌트

- `Base`: 한국어 메타데이터, 공통 메뉴와 푸터, 접근성, 가벼운 등장 효과.
- `Logo`: 이미지 로고 또는 임시 ROA 문자형 로고. 공식 로고를 받으면 설정 한 줄로 교체.
- `Section`: 제목과 원고 문단의 공통 읽기 블록.
- `Timeline`: 홈의 핵심 사건 / WORLD의 전체 공개 연표.
- `Organizations`: 원고의 세 주장을 각 조직 포스터로 표현.
- `GradeSystem`: 클릭·좌우 방향키·Home·End로 선택하는 5단계 탭.
- `IncidentSystem`: 위험도 색과 텍스트를 함께 제공하는 목록.
- 캐릭터/기록 상세 템플릿: Markdown 자료만 추가해 새 페이지 생성.

애니메이션은 CSS 중심입니다. 화면 진입 등장, 카드 hover, 지원 브라우저의 문서 전환과 가벼운 패럴랙스를 적용했습니다. `prefers-reduced-motion`에서는 모두 꺼집니다. 자바스크립트가 없어도 본문과 링크를 읽을 수 있고 등급 설명도 제공됩니다.
